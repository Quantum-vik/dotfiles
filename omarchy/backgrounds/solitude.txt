# Backgrounds for the `solitude` theme, fetched into ~/.config/omarchy/backgrounds/solitude by the
# `backgrounds` step of install.sh. The images themselves are not in this repo: they are fan art belonging to
# their artists, and this repo is public. One per line:
#
#   <filename>  <url>  [op]
#
# op is optional post-processing, applied with ImageMagick after download:
#   resize:WxH        scale to fit, for a file that is larger than any screen here
#   cropbottom:N      cut N pixels off the bottom, then rescale to 1920x1080 keeping the aspect ratio
#                     (used to remove a stock-site watermark)
#
# Sources are wallhaven.cc, queried with atleast=1920x1080 and ratios=16x9 so nothing is upscaled.
